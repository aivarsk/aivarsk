I build payment systems that don't lose money - from Oracle Tuxedo to TigerBeetle. Packt author, SREcon26 EMEA speaker.

20+ years of transaction processing, high-performance ledgers, and banking platforms. I modernize the legacy estates they run on, Oracle Tuxedo in particular, without big-bang rewrites.

## Projects

- [Fuxedo](https://fuxedo.io) - open source implementation of X/Open XATMI and the Oracle Tuxedo extensions applications actually use
- [OTELite](https://otelite.io) - disposable OTEL backend: OTLP/HTTP in, traces and metrics in one SQLite file, logs as JSONL, built for CI runs and dev clusters
- [Hisstrace](https://hisstrace.io) - syscall tracing scripted as Python coroutines
- [microSRE](https://microsre.io) - local-first Linux health checks straight from /proc, no agent stack
- [tuxedo-python](https://aivarsk.com/tuxedo-python/) - Python bindings for Oracle Tuxedo and Fuxedo
- [sysvipc-python](https://aivarsk.com/sysvipc-python/) - Python wrappers for System V IPC
- [django-taskq](https://aivarsk.com/django-taskq/) - task queue with a Celery-compatible API on the Django database

Older tools and experiments live on [github.com/aivarsk](https://github.com/aivarsk).
